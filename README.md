# Ti-memory

> 持久、可靠、可检索的个人记忆与知识管理项目。

**Ti-memory** 是一个面向个人记忆沉淀与知识管理的项目。名字取自 "Ti"（钛，象征坚固与可靠）与 "memory"（记忆），目标是构建一个长期稳定、易于沉淀与检索的个人知识库。

> 说明：项目当前处于初始搭建阶段，本 README 为项目模板。具体定位、功能与使用方式请按实际情况更新。

## 功能特性

- **结构化记忆**：以统一格式沉淀知识、灵感与日常记录
- **快速检索**：支持按关键词、标签、时间等多种维度检索
- **可扩展设计**：模块化结构，便于按需扩展
- **跨平台**：支持命令行 / Web 等多种使用方式（规划中）

> 以上为规划方向，请根据项目实际情况增删。
