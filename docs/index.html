INSPIRATION

灵感来自一段真实的顿悟

有一天你发现，脑海里两条互不相干的路，其实是同一条。

第 1 步 · 独立片段

两条路都经过 B，却互不知晓

你走过 A→B，也走过 C→B。B 是同一个 B，但在你的印象里，它们是两件完全不同的事。

第 2 步 · 交汇点

系统发现共享锚点 B

两条片段都带着锚点 B。Ti-memory 据此判定它们彼此关联，把 C→B 吸收进 A→B 所在的记忆块。

第 3 步 · 融会贯通

A→B→C 连成一条通路

系统识别出完整通路 A→B→C，生成整体描述；原来的 A→B 片段不再独立存在，只留作衰减中的溯源。

核心主张：真正记会了 A→B→C，独立的 A→B 记忆就应当消失或淡出——记忆以"块"为单位存在，而不是无限并列的碎片。
MECHANISM

六个机制，模拟记忆的沉淀与遗忘

全部逻辑可用纯 Python 复现，无第三方依赖；配置 LLM 后由大模型生成更自然的整体描述与关键词。

记忆块

记忆以"块"为单位独立存储：关键词作检索入口，块内保存融合后的整体描述。

关键词检索

检索命中关键词返回块概览；进入块内，才能看到完整描述与溯源片段。

吸收式融会贯通

新记忆共享关键词即被吸收进块；桥接多个块的片段，会把它们合并成更大的块。

片段淡出

被吸收的片段不再作为独立记忆存在，只留作带衰减强度的溯源记录（30 天半衰期）。

防止膨胀

关键词被某块完全覆盖时只吸收进最强块，不盲目合并；块总数随片段增长极其缓慢。

遗忘与加强

块强度随时间衰减，被检索/进入时加强（用进废退）；长期不用的弱块可归档清理。

    本地复现与命令行

    纯 Python 标准库实现，Python 3.9+ 即可运行；25 项核心逻辑由单元测试覆盖。

    运行演示

    # 跑完整场景：吸收、融会贯通、自动提取、遗忘
python demo.py

# 命令行：添加记忆（关键词可选）
python cli.py add "每天早上骑车去公司"
python cli.py add "从 A 走到 B" --keywords A B
python cli.py stats
python cli.py query B
python cli.py prune --threshold 0.2

# 单元测试
python -m unittest discover -s tests -v
